# Competitor capability map

This is a research guide, not a ranking.

DEKOPEN should study competitors for domain coverage and workflow lessons without copying legacy UI.

## Orgadata Logikal

Research themes:

- manufacturer/system databases;
- plausibility/configuration checks;
- CAD/element construction;
- hardware and fabrication data;
- machining/CNC;
- machine tools/clamps/operations;
- reports/MES-style production handoff.

Lesson: window software earns trust through deep technical authority, not just rendering.

## Windowmaker

Research themes:

- standard and custom design;
- bows/bays/angled products;
- revisions;
- purchasing;
- bar optimization;
- offcuts/remnants;
- labels;
- scheduling;
- remakes;
- delivery/installation.

Lesson: end-to-end continuity matters.

## Klaes

Research themes:

- CAD;
- exact materials/labor costing;
- material management;
- capacity planning;
- machine control;
- paperless shop floor;
- barcode workflows;
- dealer/webshop extensions.

## A+W Cantor

Research themes:

- quote/order continuity;
- ERP/CIM;
- materials;
- capacity;
- production;
- shipping/loading;
- installation;
- machine control.

## RA Workshop

Research themes:

- approachable window design;
- multi-material support;
- BOM;
- quotations;
- production reports;
- cutting optimization;
- CNC;
- coupling/special shapes.

## NuveraPRO / Winart / PVC Windows Studio

Useful LATAM/commercial baseline for:

- fast quotation;
- local brands/catalogs;
- materials/cubication;
- glass summaries;
- cut lists;
- margins;
- customer/proposal workflow;
- mobile/on-site simplicity.

DEKOPEN should not gain technical depth while becoming harder to use than these tools.

## Oknosoft / WindowBuilder

Important because it exposes code/domain ideas rather than only marketing.

Study concepts such as:

- contours;
- fillings;
- connections;
- layers;
- editor interaction;
- metadata-driven behavior;
- mature fenestration edge cases.

Do not transplant architecture blindly. Use it to avoid rediscovering decades of domain problems.

## Research rule

For any feature inspired by a competitor:

1. identify the user problem;
2. understand the domain rule behind the feature;
3. decide whether DEKOPEN's target user needs it;
4. fit it into DEKOPEN's own product model and workflow;
5. design a modern interaction rather than cloning the screen.
